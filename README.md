# Meadow Organics

Professional Cloudflare-ready storefront for Meadow Organics, styled from the supplied leaflet and business information.

## Included

- Responsive Meadow Organics storefront with animated, premium editorial styling.
- Product categories, stock-aware basket and checkout.
- Dojo hosted online payment integration through Cloudflare Pages Functions.
- Cash on delivery option.
- D1 inventory/order database.
- Secure HTTP-only admin session for inventory management at `/admin.html`.
- Dojo webhook that confirms successful online payment and decrements stock.
- Separate Cloudflare Worker with a nightly cron that emails **one report containing only orders going out the following day** to the business email.
- Contact details from the leaflet: `07507 196146` and `admin@meadoworganicsmcr.co.uk`.
- Instagram: https://www.instagram.com/meadow.organics.mcr/

## Payment flow

Customers place orders on the website and choose either:

- **Pay online** — the order is stored as pending, then the customer is redirected to Dojo's hosted checkout. A Dojo `payment_intent.status_updated` webhook marks the order as paid after the payment is captured.
- **Cash on delivery** — the order is stored immediately as `cash_due` and no online payment is taken.

There is no individual order email. Orders are stored in D1 and the nightly worker creates one fulfilment report for the following day.

## Cloudflare setup

### 1. Pages + D1

Create a Cloudflare D1 database called `meadow-organics`, then run `schema.sql` against a new database. Add the D1 binding as `DB` to the Pages project.

For an existing database, run `migrations/001_dojo.sql` once to add the Dojo payment-intent column.

Deploy the repository as a Cloudflare Pages project. The `functions/` directory supplies the API endpoints automatically.

### 2. Dojo secrets

Set these as Cloudflare secrets/environment variables for the Pages project:

- `DOJO_API_KEY` — the merchant's Dojo API key.
- `DOJO_API_VERSION` — optional; defaults to `2024-02-05`.
- `DOJO_WEBHOOK_SECRET` — the active secret for the Dojo webhook subscription.
- `ADMIN_EMAIL` = the business admin email.
- `ADMIN_PASSWORD` = a strong unique password.
- `ADMIN_SESSION_SECRET` = a long random secret.

Dojo API keys must remain server-side. Do not put them into browser JavaScript.

### 3. Dojo webhook

Create a Dojo webhook subscription for `payment_intent.status_updated` pointing to:

`https://YOUR-DOMAIN/api/dojo-webhook`

Use the webhook secret generated by Dojo as `DOJO_WEBHOOK_SECRET`. The endpoint verifies Dojo's HMAC-SHA256 `Dojo-Signature` before updating the order.

### 4. Nightly email worker

Create a separate Cloudflare Worker from `worker.js` using `wrangler.toml`. Replace `REPLACE_WITH_D1_DATABASE_ID` with the D1 database ID and bind the same database as `DB`.

Set:

- `RESEND_API_KEY` as a Worker secret.
- `ADMIN_EMAIL` as the destination address.
- `RESEND_FROM` as a verified sender/domain in Resend.

The cron runs nightly at `19:00 UTC` and calculates the next calendar day in the `Europe/London` timezone. It selects orders whose delivery date is tomorrow and whose status is either `paid` or `cash_due`, then sends **one consolidated report**. If there are no orders for the following day, no email is sent.

## Important production note

Do not put Dojo secrets, Resend keys or the admin password in browser JavaScript. They belong in Cloudflare secrets. The supplied frontend only calls the server-side API.
